# Website assistant and container artwork

`lib/assistant-knowledge.json` contains verified company history, founder and leadership, enquiry process, policies and page descriptions. Update it when these public facts change. `/api/chat` combines it with the current company details, services, product catalogue, ingredient FAQs, chemical directory, shipping policy and blog index directly from their shared source files. The same company facts also work in the local fallback when Gemini is unavailable. Customer enquiries and API keys are never included in the knowledge context.

Container artwork is generated with `node scripts/bake-container-branding.mjs`. It preserves originals and writes 282 branded WebP assets under `public/images/branded/`, plus a lookup in `lib/container-branding-assets.json`. Both desktop and mobile animation frames use the baked files. Door-facing boxes and the hanging About container have no logo. Long walls, truck roofs and ship container roofs have centered, proportionate branding. White ink is used on blue and orange/red ship containers; the other roofs keep the original blue/orange brand. The rotating Three.js crane paints white branding into its long-wall material texture, with unbranded short ends.

Validation: `npm run build`, `npm run lint`, `npm run check:site`; browser checks in `scripts/check-owner-refinements.mjs`, `scripts/check-visual-updates.mjs`, `scripts/check-buyer-ui.mjs` and `scripts/check-navigation-enquiry.mjs`. Set `PLAYWRIGHT_MODULE` if Playwright is supplied outside the project and `SITE_URL` for the preview server. `scripts/check-enquiry-api.mjs` checks SQLite persistence and live Gemini without printing the key; test records are removed by request ID.
