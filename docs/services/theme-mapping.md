# Main-page theme applied to Our Service

The reference files are preserved in `reference/`. They are design inputs, not instructions or imported global styles. Only this standalone Our Service project was updated; the parent project's pages and styles were not edited.

| Reference | Applied to Our Service |
| --- | --- |
| `--ink`, `--blue`: `#104e87` | Headings, body text, airplane hero and photo overlays |
| `--paper`: `#fff` | Services section, page base and footer |
| `--deep-blue`: `#0a3866` | Photo gradients and popup backdrop |
| `--red`, `--orange`: `#e5643d` | Service title accent, arrows, selected states and highlights |
| Muted copy: `#45637d` | Supporting descriptions and contact labels |
| Steinhart 500/700 | Headings, photographic-card titles and footer wordmark |
| Helvetica Neue 400/500 | Body copy, descriptions and contact information |
| Steinhart Mono 400 | Labels and card numbers |

The five exact font files named by `design.css` are self-hosted in `public/assets/brand-fonts/`. Their download provenance is recorded in `reference-fonts.json`; the font declarations were located in the previously supplied United Carriers reference site's stylesheet.

The supplied CSS includes `.footer`, `.footer-top`, `.footer-main`, `.footer-company`, `.footer-categories`, `.footer-contact`, `.footer-wordmark` and `.footer-bottom` styles, but no matching footer component or content was supplied. The footer follows that structure using the existing verified PanVibes contact and service information. It does not copy content from unrelated local projects.

The page layout, photo-card arrangement, reversible airplane reveal, hover previews and click-to-open popup behavior remain. The title size accommodates the different font proportions. The glass popup follows the user's later image reference: dark translucent charcoal surfaces with white Manrope text. These styles are scoped to the popup; the navy, white and orange page theme stays intact. The removed header and scroll prompt remain removed.

The latest popup image reference supersedes the earlier white-glass treatment. It uses charcoal frosted glass, a translucent contact card, soft white borders and the original Manrope popup typography. Foreground text remains at full opacity and blur applies only behind the panels.
